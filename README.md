# NetwiseTask

Zadanie rekrutacyjne dla Netwise. Web API pobierające losowe fakty o kotach z [catfact.ninja](https://catfact.ninja/fact) i zapisujące je do pliku `catfacts.txt`.

## Uruchomienie

```bash
cd NetwiseTask
dotnet run
```

Endpoint: `GET /fact` (np. `https://localhost:7282/fact`)

## Testy

```bash
dotnet test
```
